# Speakly

Запустите `start.cmd` и откройте http://127.0.0.1:4173/ в браузере. Оставьте окно сервера открытым. Нужен Python 3, установка дополнительных зависимостей не требуется.

Используйте HTTP-адрес вместо `file://`: встроенные браузеры могут блокировать загрузку локальных файлов из-за изоляции источников. Сервер доступен только на этом ПК.

При переходе с `file://` на HTTP браузер использует отдельное хранилище прогресса. Старые данные не удаляются, но автоматически на новый адрес не переносятся.

## Что где находится

- `index.html` — семантическая разметка и порядок подключения скриптов.
- `style.css` — темы, общие элементы и расположение библиотеки.
- `css/study.css` — уроки, карточки, тест.
- `css/responsive.css` — телефон, планшет, ПК и уменьшение анимации.
- `script.js` — переключение разделов и интерфейс.
- `js/parser.js` — парсинг слов и полных уроков, объединение повторов.
- `js/storage.js` — сохранение прогресса и темы в localStorage.
- `materials/*.txt` — девять отдельных исходных файлов. Их можно скачать из коллекций.
- `data/*.js` — те же материалы в формате для открытия без сервера.
- `data/guides.js` — дополнительные пояснения и примеры с переводом.

## Изменение материалов

Редактируйте нужный файл в `materials/`, затем выполните:

```sh
node tools/build-data.cjs
```

Это обновит соответствующие файлы в `data/`. Перезагрузите страницу.
Можно напрямую менять поле `text` в `data/*.js`, но тогда скачиваемый TXT не обновится, а следующая генерация перезапишет эти изменения.

Словарь поддерживает `слово - перевод - пример`, длинное тире, расшифровки сленга и перенос перевода на следующую строку. Уроки берутся из нумерованных разделов с подчёркнутым заголовком в файлах практики и конструкций. Ответы в уроках скрыты до раскрытия.

## Прогресс

Идентификаторы ранее выученных слов сохранены. Отдельно сохраняются прочитанные уроки. Данные принадлежат браузеру и адресу страницы; между телефоном и ПК автоматически не синхронизируются.

## Проверка

```sh
node --test tests/*.test.cjs
```

Проверки покрывают парсер, сохранность исходников, загрузку файлов и сценарии интерфейса в тестовой модели DOM. Визуальную проверку реального браузера они не заменяют.
