# Speakly

Запустите `start.cmd` и откройте http://127.0.0.1:4173/ в браузере. Оставьте окно сервера открытым. Нужен Python 3, установка дополнительных зависимостей не требуется.

Используйте HTTP-адрес вместо `file://`: встроенные браузеры могут блокировать загрузку локальных файлов из-за изоляции источников. Сервер доступен только на этом ПК.

При переходе с `file://` на HTTP браузер использует отдельное хранилище прогресса. Старые данные не удаляются, но автоматически на новый адрес не переносятся.

## Что где находится

- `index.html` — семантическая разметка и порядок подключения скриптов.
- `style.css` — темы, общие элементы и расположение библиотеки.
- `css/study.css` — уроки, карточки, тест.
- `css/responsive.css` — телефон, планшет, ПК и уменьшение анимации.
- `script.js` — переключение разделов и интерфейс.
- `js/parser.js` — парсинг слов и полных уроков, объединение повторов.
- `js/storage.js` — сохранение прогресса и темы в localStorage.
- `materials/*.txt` — двенадцать отдельных исходных файлов. Их можно скачать из коллекций.
- `data/*.js` — те же материалы в формате для открытия без сервера.
- `data/guides.js` — дополнительные пояснения и примеры с переводом.

## Изменение материалов

Редактируйте нужный файл в `materials/`, затем выполните:

```sh
node tools/build-data.cjs
```

Это обновит соответствующие файлы в `data/`. Перезагрузите страницу.
Можно напрямую менять поле `text` в `data/*.js`, но тогда скачиваемый TXT не обновится, а следующая генерация перезапишет эти изменения.

Словарь поддерживает `слово - перевод - пример`, длинное тире, расшифровки сленга и перенос перевода на следующую строку. Уроки берутся из нумерованных разделов с подчёркнутым заголовком в файлах практики и конструкций. Ответы в уроках скрыты до раскрытия.

## Прогресс

Идентификаторы ранее выученных слов сохранены. Отдельно сохраняются прочитанные уроки. Без входа данные принадлежат браузеру и адресу страницы. После входа через Google прогресс синхронизируется через настроенный Supabase.

## Темы, диалоги и песни

В словаре доступны совместные фильтры по уровню, направлению и теме. Уровни A1, A2, B1, B2 и C1 берутся из исходников; для остальных слов есть «Без указанного уровня». Уровня A3 в CEFR нет.

В разделе «Диалоги / песни» находятся 150 диалогов с фильтрами по уровню и ситуации, переводами реплик и подборкой слов. Девять песен содержат предоставленный пользователем текст: одна полностью, восемь — фрагментами. К ним добавлены пояснения выражений, грамматики и самостоятельные учебные примеры. Недостающие строки песен не дописываются.

Задания открываются внутри материала: выбор перевода для диалогов и песен, пропуски в учебных примерах песен. Ответы попадают в общий журнал ошибок; результат сохраняется в `lastQuiz.mediaResult`. Незавершённое занятие не восстанавливается после перезагрузки. Разбор ошибок, повторения и короткие уроки открываются на отдельном экране с возвратом в предыдущий раздел.

`js/media-data.js` разбирает исходники и содержит пояснения; `js/media.js` отвечает за библиотеку и практику.

## Проверка

```sh
node --test tests/*.test.cjs
```

Проверки покрывают парсер, сохранность исходников, загрузку файлов и сценарии интерфейса в тестовой модели DOM. Визуальную проверку реального браузера они не заменяют.

## Практика по предложениям

Коллекция «Предложения A1–C1» включает 3000 строк нового файла с фильтрацией по уровню. Раздел «Практика» поддерживает выбор перевода, ввод пропущенного слова и сборку фразы. Занятие содержит до 10 подходящих предложений из текущих фильтров. Числовые варианты одинакового шаблона не дублируются в одном занятии.

`js/training.js` отвечает за новые задания. Суммарное число попыток и верных ответов хранится в `lastQuiz.practiceStats` и использует существующую синхронизацию Supabase без изменения таблицы. Незавершённое занятие при перезагрузке начинается заново. Проверяется вариант из исходного материала, а не все допустимые английские формулировки.

## Обучение, повторения и качество

- На главной: «Повторить сегодня», «Разобрать ошибки», «Короткий урок».
- Ошибка доступна для разбора сразу. После успешного ответа в тот же день она возвращается через 24 часа после последней ошибки; успешное повторение на следующий день убирает её из журнала.
- Карточки: «Не помню» — повтор через 10 минут; «Сложно» — от 1 дня; «Легко» — от 3 дней. Дальше интервалы увеличиваются, максимум 180 дней. Это простой планировщик, не полноценный SM-2/FSRS.
- Шесть коротких уроков: правило, пример, пять контролируемых заданий, объяснение и разбор ошибок. Результат урока сохраняется.
- Сокращения вроде I'm/I am и некоторые перемещения обстоятельств времени принимаются автоматически. Для других корректных вариантов есть явная самооценка «Мой вариант тоже верен». Это не универсальная проверка грамматики.
- `js/quality.js` исправляет конкретные выявленные проблемы; `Learning.cleanEntries` убирает повторы и отмеченные неестественные фразы из подборки. Исходники и ID не удаляются.
- `node tools/audit-content.cjs` обновляет `data/quality-report.json`. Проверка качества сочетает конкретные редакторские правки и автоматические правила; все предложения не проходили полную ручную лингвистическую вычитку.

Расписание, журнал ошибок и результаты уроков хранятся в `lastQuiz.learning` в отдельном локальном хранилище аккаунта и синхронизируются через существующую таблицу Supabase. Дополнительный SQL не требуется. Эта сводная запись при одновременной работе двух устройств использует последнюю запись на сервере; независимого разрешения конфликтов для каждого элемента расписания пока нет. Незавершённый мини-урок после перезагрузки начинается заново.
