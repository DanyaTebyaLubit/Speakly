# Подключение Supabase и входа через Google

Проект уже указан в `supabase-config.js`. Публичный ключ допустим в браузере; доступ к прогрессу ограничивает RLS.

## 1. Создать таблицу

В [SQL Editor проекта](https://supabase.com/dashboard/project/opqefedphlfatpdvqted/sql/new) выполните содержимое `supabase/schema.sql`.

## 2. Включить Google

В Google Cloud создайте OAuth client типа **Web application**:

- Authorized JavaScript origins: `http://localhost:4173` (для Google используйте localhost вместо IP).
- Authorized redirect URIs: `https://opqefedphlfatpdvqted.supabase.co/auth/v1/callback`.
- Для приложения в статусе Testing добавьте свой Google-аккаунт в Test users.

В Supabase → Authentication → Sign In / Providers → Google включите провайдера, сохраните Client ID и Client Secret из Google Cloud. Client Secret вводится только в панели Supabase, не в файлах сайта.

## 3. Разрешить возврат в приложение

Supabase → Authentication → URL Configuration:

- Site URL: `http://localhost:4173/`.
- Redirect URLs: `http://localhost:4173/`, `http://localhost:4173/index.html`, `http://127.0.0.1:4173/`, `http://127.0.0.1:4173/index.html`.

Для размещённого сайта добавьте его точный HTTPS-адрес. Локальный сервер доступен только на этом ПК; чтобы использовать приложение на телефоне, нужен доступный телефону адрес сайта с разрешённым OAuth redirect.

## 4. Проверить

Запустите `start.cmd`, откройте `http://localhost:4173/` в обычном Chrome/Edge и нажмите «Аккаунт → Войти через Google». Google может запрещать вход во встроенных браузерах.

1. После возврата должна появиться почта аккаунта и статус синхронизации.
2. Отметьте слово и урок. Обновите страницу: открывается словарь, отметки остаются.
3. Войдите тем же аккаунтом в другом браузере: отметки загрузятся.
4. Выйдите: вернётся отдельный гостевой прогресс.
5. Для переноса старых гостевых отметок нажмите «Перенести гостевой прогресс», находясь на том же адресе, где они были сохранены.

Сохраняются выученные слова, прочитанные уроки и результат последнего теста. Снятие отметки тоже синхронизируется. Очередь изменений сохраняется локально при потере сети. Разные отметки не перезаписывают друг друга; при одновременном изменении одной отметки на двух устройствах побеждает последняя запись на сервере. Прогресс обновляется после изменений, возврата фокуса, восстановления сети и по кнопке синхронизации.

Официальная инструкция: https://supabase.com/docs/guides/auth/social-login/auth-google
